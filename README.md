# AZILE

そこそこ文法解析をして、そこそこ会話します。
サーバー不要・静的ファイルのみで動くので、GitHub Pages にそのまま置けます。

- キャラクター: フレンドリーな大人の女性。漫画・アニメ風のセリフで励ましてくれる。法律と物理の話が得意でジョークにする。
- 画面: 往年のコンソール画面を現代風にアレンジ（フォスファーグリーン／アンバー、薄いスキャンライン、タイプライタ表示）。
- 放っておくと AZILE のほうからランダムに話しかけてきます（45〜90 秒、無反応が続くと間隔が伸びる。タブが非表示の間は黙る）。

## できること

| 話しかけ方 | 動作 |
|---|---|
| ふつうの会話（「仕事が不安」「猫が好き」…） | 形態素解析でキーワードを拾い、Eliza 式のルールで返答。話題を記憶して後で蒸し返す |
| 「私は〇〇」「名前は〇〇」 | 名前を覚える（localStorage）。次回から名前で呼ぶ |
| 「民法709条って何？」「刑法第百九十九条」「憲法9条」 | **e-Gov 法令API v2** から本物の条文を引用 |
| 「万引きって法律的にどう？」「残業代が出ないのは違法？」 | e-Gov の条文全文検索で関係法令を提示（口語→条文用語の言い換え付き） |
| 「エントロピーって何？」「量子コンピュータについて教えて」 | **Wikipedia 日本語版** の要約を引用＋物理ジョーク |
| 「光速はいくつ？」「プランク定数を教えて」 | 内蔵の CODATA 2022 定数表から回答 |
| 「今日の天気は？」 | **Open-Meteo** で現在の天気（位置情報を許可すると現在地、拒否時は東京） |
| 「猫の画像を作って」「走る犬のイラストを描いて」 | いらすとや の検索結果ページへのリンクを表示 |
| 「〇〇って何？」 | Wikipedia で調べて要約 |
| 「冗談言って」「励まして」「名言」「雑学」 | 内蔵データから |

コマンド: `/help` `/name 名前` `/clear` `/reset`（履歴・名前・機嫌・キャッシュ全消去） `/engine`（解析エンジン状態） `/memory` `/time`
隠しコマンド: `/mood`（機嫌の現在値と直近の変動理由を表示） `/diary`（嘘日記を 1 本）

## 穴埋めネタ

「俺をおいて{n}かよ、ロイエンタール！」のように、会話に出てきた名詞やユーザー名を差し込むパロディ台詞を 35 本内蔵しています（[persona.js](js/data/persona.js) の `madlibs`）。
名詞は「今の発言 → 直前の発言 → 記憶している話題 → 既定語」の順で選びます。「名言」「セリフ」と頼んだときや、返答の味付けとしてランダムに出ます。

## 隠しパラメータ「機嫌」

0〜100（平常値 70）の機嫌を [mood.js](js/mood.js) が管理し、localStorage に保存します。画面には数値を出しませんが、`AZILE>` のラベル色がじわっと変わります（上機嫌: 明るい緑 / ふつう: 緑 / ややご機嫌ななめ: 琥珀 / 不機嫌: 赤）。

| 下がる | 上がる |
|---|---|
| ネガティブな発言（−4） | ポジティブな発言（+4） |
| 暴言（−15） | 褒め言葉（+12）、感謝（+8） |
| 無操作で話しかけるとき（−2） | 名前を教える（+6）、自分のことを聞かれる（+3） |
| 話しかけたのに無視される（−8 ずつ、3 回まで） | 笑ってくれる（+3〜6）、プレゼント（+10） |
| 長期間放置（2 日以上 −2、7 日以上 −5） | 謝ってくれる（機嫌が悪いとき +12） |

- 会話が続いているあいだは 1 ターンごとに 1 ポイント平常値へ戻り、離れている間も 1 時間あたり約 9 ポイント平常値へ回復します。
- 機嫌が悪いと口調が変わります（「！」が「。」に、「…」が増える、ジョークを渋る、「今そういう気分じゃない」）。上機嫌だと「♪」や穴埋めネタが増えます。
- **無視されたときの反応**: 話しかけても無操作が続くと「聞こえてる？」→「無視？」→「拗ねる」と段階的に反応し、4 回目以降は基本的に黙ります。戻ってきて何か話すと、機嫌に応じて「おかえり」か「今さら？」で迎えます。

## 立ち絵

[image/](image/) にある 6 枚のドット絵風立ち絵を、チャット窓の右側のパネルに表示し、返答の感情に合わせて切り替えます（幅 760px 以下では出力欄の右下に小さく半透明で重ねます）。
Web 表示用には透明部分をトリミングして高さ 720px に縮小した [image/web/](image/web/) を使い、元画像はそのまま残しています。

| ファイル | 感情 | 出るとき |
|---|---|---|
| azile_nomal | 通常 | 条文引用・物理解説・雑学など |
| azile_uresi | 嬉しい | 褒められた、感謝、名前登録、あいさつ、ポジティブな話題、上機嫌 |
| azile_kanasi | 悲しみ | ユーザーがつらい話をしている、最初の無視、長期放置後、別れのあいさつ |
| azile_ikari | 怒り | 暴言、無視が続く、不機嫌なとき全般 |
| azile_raku | 脱力 | ジョーク・穴埋め台詞、深夜、ややご機嫌ななめ |
| azile_housin | 放心 | API に届かなかった、話が読めなかった（フォールバック）、エラー |

1 行ごとに立ち絵が決まるので、本文で「悲しみ」→ 励ましで「嬉しい」→ ジョークで「脱力」のように会話の流れで表情が動きます。表情は履歴と一緒に保存され、リロード後も直前の表情から始まります。

## 今日の嘘日記

放置中の話しかけの約 25% と、「日記」「今日何があった？」と聞いたとき、`/diary` で、テキトーな今日の出来事を話します。
[persona.js](js/data/persona.js) の `diary` にテンプレート 30 本と、モノ 57 語・場所 28 語・人物 29 語の穴埋め語彙があり、3 割の確率で会話に出た名詞も混ざります。

> 今日の天気は、ハムスターだったね。ハムスター。拾ってきた？
> 今日街を歩いてたら宗教勧誘の人にあっちゃってさ。無理矢理渡されたんだよね。六法全書。
> さっき自動販売機の裏に行ったら、アインシュタインが万有引力を配ってた。3つもらった。

## 時間帯

`new Date()` はブラウザを動かしている端末のローカル時刻を返すので、サーバーなしでもユーザーの場所の時間になります（`/time` で時刻とタイムゾーン名を表示）。
朝 5–10 / 昼 10–17 / 夕 17–19 / 夜 19–23 / 深夜 23–5 で起動時のあいさつと無操作時の話題が変わり、深夜は「寝たら？」系が増えて機嫌もやや渋くなります。時間帯と合わないあいさつ（夜中の「おはよう」）にはツッコみます。曜日ネタも少し。

## 構成

```
index.html                画面骨格
css/style.css             コンソール風テーマ
js/lib/tiny_segmenter.js  TinySegmenter（工藤拓氏、BSD ライセンス）
js/analyzer.js            形態素解析の抽象層（TinySegmenter → kuromoji.js に自動切替）
js/kuromoji-worker.js     kuromoji.js を動かす Web Worker（辞書構築と解析を別スレッドで）
js/data/persona.js        セリフ・ジョーク・定数・法令名テーブルなど静的データ
js/data/rules.js          Eliza ルール表（キーワード／分解パターン／再構成テンプレ）
js/api.js                 e-Gov / Wikipedia / Open-Meteo ラッパー
js/brain.js               意図判定と応答生成
js/ui.js                  端末描画・タイプライタ・アイドルタイマー
js/storage.js             localStorage
js/mood.js                機嫌（隠しパラメータ）と時間帯
js/app.js                 起動と配線
```

### 形態素解析

起動直後は辞書不要の TinySegmenter で即応答し、裏で kuromoji.js の辞書（jsDelivr CDN、初回約 18 MB・以降はブラウザキャッシュ）を読み込みます。
辞書の展開・構築と形態素解析は [js/kuromoji-worker.js](js/kuromoji-worker.js) の **Web Worker** で行うので、メインスレッド（画面）は一切ブロックされません（以前はメインスレッドで構築していたため、遅い環境で「ページが応答しません」になることがありました）。
読み込み中はヘッダーに `ENGINE: TINY ● 辞書DL中` と出て、終わると `ENGINE: KUROMOJI` に変わり、品詞・基本形付きの解析に切り替わります。読み込みに失敗しても TinySegmenter のまま動きます。

### 外部 API（すべて認証不要）

| API | 用途 | ライセンス／出典表記 |
|---|---|---|
| [e-Gov 法令API v2](https://laws.e-gov.go.jp/) （デジタル庁） | 条文取得・条文全文検索 | 法令データ（出典: e-Gov法令検索） |
| [Wikipedia 日本語版 REST API](https://ja.wikipedia.org/api/rest_v1/) | 用語の要約、ランダム記事 | 本文は CC BY-SA 4.0 |
| [Open-Meteo](https://open-meteo.com/) | 現在の天気 | CC BY 4.0 |
| [いらすとや](https://www.irasutoya.com/) | 画像リクエスト時の検索リンク | リンクのみ |

通信に失敗した場合は内蔵データで会話を続けます（オフラインでも動作）。

## ローカルで動かす

`file://` では kuromoji の辞書を fetch できないので、HTTP サーバー経由で開いてください。

```
python -m http.server 8080
# → http://localhost:8080/
```

## GitHub Pages

リポジトリの Settings → Pages で `main` ブランチのルートを公開すれば、そのまま動きます（相対パスのみ使用）。
